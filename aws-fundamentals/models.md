# **Quick Comparison**

[← Back to AWS Fundamentals](readme.md)

> Define how much of the technology stack you manage versus what the cloud provider handles.

| **Model** | **What It Provides** | **What You Manage** | **Example** |
| --- | --- | --- | --- |
| **IaaS** *(Infrastructure as a Service)* | Raw compute (virtual machines), storage, and networking | Operating system, middleware, runtime, and applications | Amazon Web Services (AWS) EC2, Microsoft Azure VMs |
| **PaaS** *(Platform as a Service)* | Complete application development and deployment environment (runtimes, databases, tools) | Your custom application code and data | Heroku, Google App Engine |
| **DBaaS** *(Database as a Service)* | Fully managed database hosting and maintenance | Database queries, schemas, and data content | Amazon RDS, MongoDB Atlas |
| **FaaS** *(Functions as a Service / Serverless)* | Event-driven code execution (runs only when triggered) | Only the individual function code and its triggers | AWS Lambda, Google Cloud Functions |
| **SaaS** *(Software as a Service)* | Ready-to-use software applications accessed via a web browser | User access, basic settings, and data | Salesforce, Zoom, Microsoft 365 |
